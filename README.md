# rms-careers/.github

Organisation-wide defaults for the RMS Careers curriculum repositories:

- `profile/README.md`: the page people see at https://github.com/rms-careers
- `CODE_OF_CONDUCT.md`, `SECURITY.md`, `CONTRIBUTING.md`: inherited by every public repository in this organisation that does not have its own
- `ISSUE_TEMPLATE/`, `pull_request_template.md`: default issue forms and pull request template

These defaults apply only to repositories **in this organisation**. Repositories that students create from a template live
in their own accounts and do not inherit them.
