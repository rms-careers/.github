# Security

If you find a security problem in a template, for example a starter that commits secrets, an unsafe default or a
vulnerable dependency, please **do not open a public issue**.

Use GitHub's **Report a vulnerability** button on the repository's Security tab, or write to **engineering@rms-careers.com**.
We aim to reply within 5 working days.

Problems with the RMS Careers student portal itself (student.rms-careers.com) should go to the same address.
