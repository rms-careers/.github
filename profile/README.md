# RMS Careers: Learn · Build · Get Placed

Curriculum material for the **RMS Careers Career Readiness Program**, a 26-week program for B.Tech students delivered in
partnership with colleges.

This organisation holds **starter templates, datasets and the student handbook**. It does not hold student work: every
student builds in their **own** GitHub account, so each project stays part of their portfolio after the program.

## Start here

| If you are... | Go to |
|---|---|
| A student starting the program | [program-handbook](https://github.com/rms-careers/program-handbook): setup, repo rules and how to submit |
| A student starting Week 1 | [template-weekly-labs](https://github.com/rms-careers/template-weekly-labs): click **Use this template** |

Projects are assigned and submitted in your batch workspace at
[student.rms-careers.com](https://student.rms-careers.com). The brief there is always the source of truth.

## How templates are versioned

Each template is tagged with the syllabus version (`v1.0`, ...). Your project brief links to the tag your batch uses,
so later changes never move the ground under a running batch.

## Found a problem in a template?

Open an issue in that repository using the **Template problem** form. Please do not post solutions to assignments in
issues or pull requests.
