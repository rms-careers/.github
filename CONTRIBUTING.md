# Contributing

Template and handbook changes are made by the RMS Careers curriculum team.

**Students and tutors:** if you spot a mistake, open an issue with the **Template problem** form. Please do not open
pull requests that add solutions.

**Curriculum team:**
1. Branch from `main`; one change per pull request.
2. Templates must contain no answers: no solved queries, finished components or completed documents.
3. Note the change in the pull request using the template, including which weeks and briefs it affects.
4. A change that a running batch would notice is released as a patch tag (`v1.0.1`) and announced to tutors.
